# Бие Даалт OOP 2026

Объект хандлагат програмчлалын бие даалтын ажил. Төсөл нь Java Swing дээр хийсэн банкны бүртгэл, данс болон гүйлгээний удирдлагын систем юм.

## Төслийн зорилго

Энэхүү project нь OOP-ийн үндсэн ойлголтуудыг бодит код дээр хэрэгжүүлж харуулах зорилготой. Системд хэрэглэгч болон админ нэвтрэх, данс үүсгэх, орлого зарлага хийх, данс хооронд шилжүүлэг хийх, хайлт эрэмбэлэлт хийх, өгөгдлийг файлд хадгалах боломжууд багтсан.

## Гол боломжууд

- Админ болон хэрэглэгчийн нэвтрэлт
- Хадгаламжийн болон харилцах данс үүсгэх
- Орлого, зарлага, данс хоорондын шилжүүлэг хийх
- Гүйлгээний түүх харах
- Данс хайх болон эрэмбэлэх
- CSV файлд өгөгдөл хадгалах, унших
- Swing GUI ашигласан интерфэйс

## OOP ойлголтууд

- `AccountOperations` interface болон `implements`
- `Account` abstract sealed class
- `SavingsAccount`, `CurrentAccount` inheritance
- Method overriding болон overloading
- Runtime болон compile-time polymorphism
- Composition, aggregation, association
- Constructor, `this`, `super`
- File I/O, validation, exception handling
